04 — Projects

Projects

Oxyrhynchus Papyri — OCR & Machine Learning

Final-Year Project

My final-year engineering project: a from-scratch OCR and machine learning pipeline that reads Ancient Greek handwriting on the Oxyrhynchus papyri. The recognition engine — line segmentation, character detection, and classification networks, plus the CUDA matrix-multiply kernel they run on — is all custom-built rather than using off-the-shelf OCR. Decoding can optionally lean on a Homer-aware language model (many fragments are Iliad text) to correct recognition errors against the known edition, and the whole pipeline is deployed to run on a Jetson Nano for on-device inference, with a web demo for inspecting segmentation, detections, and decoded text against ground truth line by line. Still in progress — I'm currently writing up the final report.
